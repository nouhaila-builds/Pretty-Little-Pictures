# English

**Looks can be deceiving — even to a machine.**

Independent research case study. It asks whether pixel fidelity, perceptual similarity, and pedestrian-detection utility degrade together when a visible-to-infrared translator is trained on fewer aligned pairs.

The protocol has been run. Measured scores are in `web/public/data/experiments.json`. The page reads that file. Images, checkpoints, and result archives are not in git.

# Français

**Les apparences peuvent être trompeuses — même pour une machine.**

Étude de cas de recherche indépendante. Elle cherche à déterminer si la fidélité aux pixels, la similarité perceptuelle et l'utilité pour la détection de piétons se dégradent conjointement lorsqu'un traducteur visible–infrarouge est entraîné avec un nombre réduit de paires alignées.

Le protocole a été exécuté. Les scores mesurés se trouvent dans `web/public/data/experiments.json`. La page lit directement ce fichier. Les images, checkpoints et archives de résultats ne sont pas inclus dans Git.
